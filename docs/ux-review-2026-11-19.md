# HL Central (Harbor) — UI and UX review, Nov 19 2026

The preview build of the `redesign` branch was reviewed in a headless browser at three sizes: desktop (1440px), laptop (1280px) and phone (iPhone 13). It was checked as an Admin, a Manager and a Member, using sample data. No code was changed during the review.

**Counts:** 0 Blocker · 10 Major · 28 Minor · 17 Polish. One reported Major, "My team is empty", turned out to be the agreed design. It is listed under Minor as a decision to make.

## Top issues to fix first

1. **Dropdowns can't be used from the keyboard.** This affects every Harbor Select. Focus never enters the list, so ↓ and Enter just reopen it. `Select.tsx` focuses the list while `Popover.tsx` still renders it hidden.
2. **The task page on a phone is 754px wide.** Request update, Mark done and ⋯ end up off-screen.
3. **Hovering an Organization person card turns it navy with unreadable dark text.** A global `button:hover` rule in `styles.css` (~2573) overrides `.hb-ocard-main`.
4. **The comment composer's Discard button has about 2:1 contrast** (grey on red). This is in `Comments.tsx` (~511), where `button.secondary` and `button.danger` clash.
5. **The Users side panel is covered by the table's header strip.** The action column is also cut off ("Re…").
6. **A mention can go to the wrong person.** `@Mi` + Enter picked System Administrator, whose email "adMIn" matched, instead of Mike. Name matches should rank first.
7. **"Due date, Soonest" lists tasks with no date above overdue ones** (Tasks, All tasks).
8. **The Tasks list breaks at smaller widths.** On a phone, titles are cut to about 6 characters. At 1280px, the Priority column is cut off.
9. **Time Review leaves out "No duty" timer time.** The Admin showed 9:04 in Review but 9:29 on My Time.
10. **About 9 confirmations still use the browser's own confirm box:**
    - `TemplatesPage.tsx` (2)
    - `DraftsPage.tsx`
    - `GoalPanel.tsx` (2)
    - `DayPanel.tsx` (2)
    - `EventPanel.tsx`
    - Google Calendar disconnect
    - `useUnsavedChangesWarning.ts`

## By screen

### Shared (all screens)
- **Major:** Select keyboard use. See Top 1.
- **Minor:** Native `window.confirm` in about 9 places. See Top 10.
- **Minor:** Browser-native validation tooltips on /login, /forgot-password and Add user. Use `noValidate` with inline errors.
- **Minor:** No 404 or "not allowed" page. Unknown and restricted URLs silently land on the Dashboard (`router.tsx`).
- **Minor:** Developer wording is visible to users:
  - environment variable names on the Connect page and in Settings › Connect sign-in;
  - "needs a backend change";
  - "in this phase" on Alert Groups.
- **Minor:** Tiptap warns "Duplicate extension 'underline'" every time an editor opens.
- **Polish:** `index.html` preloads a font that is never used.
- **Polish:** Toasts cover the bottom of the content.
- **Polish:** Date ranges are written in different formats on different screens.
- **Polish:** Signing out calls `DELETE /api/connect-auth/session`, which returns 404 when Connect sign-in isn't set up. It's harmless, but it's an error in the console.

### Sign in and reset password
- **Minor:** "Keep me signed in" comes before Email in Tab order, and Email isn't focused when the page opens.
- **Polish:** The error banner shifts the layout, and the checkbox hint is very light grey.
- **Polish:** The phone sign-in page has no brand.
- **Polish:** The reset page has no "Back to sign in" link and no show-password toggle.
- Session expiry works well, both the "Still there?" prompt and the message on sign-in.

### Dashboard

  - a manager's direct report with no duty never appears;
  - Admins see only people who hold a duty, while Calendar › Team shows them everyone.

  Should My team also include direct reports, and for Admins everyone?

- **Polish:** The Alerts filter chips wrap onto two lines, and alert text is cut off.
- **Polish:** At 1280px the search placeholder is cut off.
- **Polish:** The two rows of stat tiles are uneven.
- **Polish:** On a phone the bell sits on its own line, and the page is very long.

## Works well
- The bell, the New menu and the apps launcher take focus correctly and close on Escape.
- These all behave as expected:
  - Snooze, Request update and the timer;
  - the Compare before/now pop-ups;
  - Departments;
  - the Sign out everywhere confirmation;
  - the session-expiry warning.
- No unlabelled buttons or inputs were found on the 10 key screens checked.
- Routes load in 0.6–1.3s on the dev server.

## Not tested
- File upload, voice notes and screen recording: no storage or devices here.
- Browser push, Google Calendar, a linked Connect and email: not configured in the preview.
- Drag-and-drop on Organization, Board and Gantt.
- Recurring templates firing: the scheduler is off in the preview.
- Saving a new calendar event.
